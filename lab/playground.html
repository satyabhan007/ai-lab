🌡️ Sampling · Lab 7

🌡️ Lab 7 — Temperature, Top-K & Top-P Explorer live

ChatGPT's creativity dial, fully exposed. Temperature scales logits before softmax. Top-K and Top-P (nucleus sampling) are additional tricks used in every production LLM.

ChatGPT creativity🎨 DALL-E varietyDiscover Weekly
Greedy = T→0. Random = T→∞. Production ChatGPT uses T≈0.7 + Top-P≈0.9 to balance coherence and creativity.
🎯 Challenge: T=0.1 → always picks "mat". T=2.0 → occasionally picks "moon". Set Top-K=2 → only top 2 words allowed. Set Top-P=0.7 → nucleus sampling. Real GPT-4 uses Top-P=0.9 by default.

🔄 Backpropagation · Lab 8

🔄 Lab 8 — Backpropagation Step-by-Step new

Backprop is just the chain rule applied backwards through a computation graph. Watch gradients flow from the loss back to every weight — this is literally how GPT learns.

GPT training🧬 AlphaFold

👆 Press Forward pass then Backward pass — watch gradients propagate

Press Forward pass to begin
Chain rule: ∂Loss/∂w = (∂Loss/∂output) × (∂output/∂w). Every layer multiplies its local gradient by the incoming gradient. Gradients can vanish (too small) or explode (too large) in deep networks — why residual connections and LayerNorm exist.
🎯 Challenge: Set x=3, w=2 → large gradient on w. Set x=0 → gradient of w = 0 (dead weight!). This is the "dying ReLU" problem — why initialization matters enormously.

🗺️ Lab 9 — Vector Embeddings & Similarity new

Cosine similarity measures the angle between vectors, not distance. GPT-4 uses 12,288-dimensional embeddings — we visualise a 2D projection here.
🎯 Challenge: king vs queen → high similarity (~0.97). cat vs france → low (~0.2). Try the analogy: king − man + woman. Result should be nearest to "queen" — this is why word2vec was revolutionary in 2013.

🔮 Lab 10 — Transformer Architecture Walk-Through new

Architecture: Input tokens → Embedding (d=64) → Positional Encoding → × N layers (Attention + Add&Norm + FFN + Add&Norm) → Linear → Softmax → next token probabilities. GPT-4 has 96 layers, 96 heads, d=12288.
🎯 Challenge: After embedding, each word is a 64-dim vector. After attention, it contains context. After FFN, it has "knowledge" about grammar and facts. After softmax, it's a probability distribution. Step through all layers to see this unfold.

⚙️ MatMul & Complexity · Labs 11–12

🧮 Lab 11 — MatMul Visualizer live

C[i][j] += A[i][k] · B[k][j]. Every GPU, every neural net, every attention head runs this triple loop — billions of these sit behind every ChatGPT reply.

step through the loop ↑
GPU parallelism: CPUs do 1 cell at a time (this demo). A GPU does all n² cells simultaneously using CUDA cores — that's why training on GPU is 1000× faster.

📈 Lab 12 — Context Cost: Attention is O(n²) live

Every token scores every other token. Double the context = 4× the compute. This is the fundamental reason Flash Attention, KV caches, and sliding-window attention exist.

ChatGPT long chats📄 Claude 200K⚡ Flash Attention
Why it matters: 32K context (GPT-4) = 1B attention scores per layer. 128K context (Claude) = 16B scores. Flash Attention reorganises the computation into tiled blocks that fit in GPU SRAM, bypassing memory bandwidth bottlenecks.
